# Communication de lancement

Les textes de diffusion de l'application, à copier tels quels. Quatre longueurs
pour le même fond, plus les arguments à ressortir selon l'interlocuteur.

Source des fonctionnalités : la page Notion « Les features » (version 3.8.0).
Les astérisques sont le gras de WhatsApp ; sur un autre support, mettre en gras.

Rappel de forme : pas de tiret long, et les espaces insécables du français
(U+202F avant `!` `?` `;`, U+00A0 avant `:`) sont déjà dans les textes
ci-dessous. Un copier-coller les emporte avec lui.

## Pourquoi télécharger l'application, et pas seulement ouvrir le site

À ressortir quand on vous répond « le site me suffit ». Ce sont les quatre
choses que le site ne peut pas faire :

- les **widgets** d'écran d'accueil : le prochain horaire, la date hébraïque,
  la paracha, votre lecture du jour, sans ouvrir quoi que ce soit ;
- les **rappels** de lecture, à heure fixe ou 20 minutes avant la chkia ;
- la **lecture hors ligne complète** : les livres téléchargés restent lisibles
  en mode avion ;
- les **liens qui s'ouvrent dans l'app** : un lien petite-jerusalem.fr reçu par
  message ouvre directement la bonne page.

## Angles selon l'interlocuteur

- **Une chaîne de Tehilim à organiser** : le partage de lectures, le lien et le
  QR code, la participation sans compte.
- **Un groupe qui veut finir le Chass** : la répartition des daf et le suivi
  jusqu'au siyoum.
- **Quelqu'un qui cherche juste les horaires** : les zmanim calculés sur
  l'appareil, sans que la position parte nulle part, et le widget.
- **Quelqu'un qui prie déjà** : le sidour qui suit le calendrier, pour ne plus
  se demander ce qu'on dit aujourd'hui.
